# Suzanne 紙飛機飛行實驗室

一個為國小課堂設計的互動式紙飛機飛行模擬器。學生可以調整 Suzanne 紙飛機的迴紋針配重、投擲角度、力道、風向與天氣，觀察飛行距離、高度、滯空時間和側偏變化。

![飛行模擬器](assets/flight-simulator.png)

## 功能

- Suzanne 紙飛機 3D 模型與平滑飛行動畫
- 機身、左翼、右翼及左右對稱迴紋針配重
- 小型、中型、大型翼面積選擇與即時升力／阻力計算
- 即時風場、陣風、亂流、姿態恢復／失速及紙翼彈性反應
- 飛行中暫停、單步推進、受力箭頭與即時儀表
- 距離、高度、滯空時間、重心與側偏估算
- 正面風、左側風與右側風控制
- 晴天、下雨與颱風環境
- 颱風亂流、斜向暴雨、風粒子與樹木搖晃
- 側視、跟隨與全景觀看模式
- 慢動作重播與飛行關鍵事件提示
- 適合手機、平板及桌面電腦的響應式介面

## 即時風場飛行實驗

在「紙飛機大小」選擇小型、中型或大型翼面積，再試飛比較距離、高度和滯空時間。飛行時，模擬器會逐步更新飛機位置、速度、仰俯、側傾和轉向；風場會改變相對空氣速度，並依空氣密度、迎角、翼面積、紙飛機重量估算升力和阻力。

「風場實驗」可調陣風強度、亂流程度、陣風出現時間和機翼柔軟度。飛行期間可以暫停或單步推進；即時儀表顯示空速、風速、仰角、側傾、迎角、升力和阻力。受力檢視會顯示升力、阻力、重力、前進方向和風力箭頭。風場採固定種子，因此相同設定可重複比較。柔軟度會讓兩側紙翼產生視覺彎曲，目前不會改變氣動力計算。

本功能使用即時簡化氣動力學，不是逐點求解空氣流場的 CFD 或風洞模擬。氣動係數、姿態恢復、失速條件和場景尺度是教學近似，適合觀察參數間的相對影響，不應用來精準預測真實紙飛機的飛行距離。

## 技術

- React 19
- Vite 7
- Three.js
- Lucide React

## 本機執行

需要 Node.js 20 或更新版本。

```bash
npm install
npm run dev
```

開啟終端機顯示的本機網址即可使用。

## 正式建置

```bash
npm run build
```

輸出檔案位於 `dist/`。專案使用相對資源路徑，因此可將 `dist` 內容部署到 XAMPP 的子資料夾，例如：

```text
C:\xampp\htdocs\paperplane\
```

## 課堂用途

建議讓學生先建立基準試飛，每次只調整一個變因，先預測結果再重新試飛，比較配重、風向與環境對飛行的影響。
