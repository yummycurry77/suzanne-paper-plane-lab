# Suzanne 紙飛機飛行實驗室

一個為國小課堂設計的互動式紙飛機飛行模擬器。學生可以調整 Suzanne 紙飛機的迴紋針配重、投擲角度、力道、風向與天氣，觀察飛行距離、高度、滯空時間和側偏變化。

![飛行模擬器](assets/flight-simulator.png)

## 功能

- Suzanne 紙飛機 3D 模型與平滑飛行動畫
- 機身、左翼、右翼及左右對稱迴紋針配重
- 小型、中型、大型翼面積選擇與即時升力／阻力計算
- 即時風場、陣風、亂流、姿態恢復／失速及紙翼彈性反應
- 飛行中暫停、單步推進、受力箭頭與即時儀表
- 距離、高度、滯空時間、重心與側偏估算
- 正面風、左側風與右側風控制
- 晴天、下雨與颱風環境
- 颱風亂流、斜向暴雨、風粒子與樹木搖晃
- 環視為預設視角，也可切換側視、跟隨與全景
- 360°環視紙飛機：右鍵移動旋轉視角、WASD 平移鏡頭，飛行中也可觀察
- 依實驗目標整理紙飛機、投擲和風場設定，進階氣流參數可收合
- 提供初始高度設定、快速實驗情境和固定的試飛操作按鈕
- 預設投擲力道提高，並加強出手速度；完成基準飛行後，預測選項會顯示在右下角試飛按鈕旁
- 調整投擲角度時，待飛紙飛機會同步改變機頭角度；投擲力道會改變發射方向箭頭長度
- 投擲角度可設定 0° 到 90°；飛機落地後調整設定，視角會平順移回發射點並重新對準紙飛機
- 快速實驗情境會標示目前選項；距離標記、跑道與景物延伸至約 70 公尺，最遠標記為 70 公尺
- 慢動作重播與飛行關鍵事件提示
- 每次試飛落地時保留半透明紙飛機殘影，並標記「第 N 次投擲」；重播不會重複新增紀錄，紀錄保留到重新載入頁面
- 適合手機、平板及桌面電腦的響應式介面

## 即時風場飛行實驗

在「紙飛機大小」選擇小型、中型或大型翼面積，再試飛比較距離、高度和滯空時間。飛行時，模擬器會逐步更新飛機位置、速度、仰俯、側傾和轉向；風場會改變相對空氣速度，並依空氣密度、迎角、翼面積、紙飛機重量估算升力和阻力。

「風場實驗」可調陣風強度、亂流程度、陣風出現時間和機翼柔軟度。飛行期間可以暫停或單步推進；即時儀表顯示空速、風速、仰角、側傾、迎角、升力和阻力。受力檢視會顯示升力、阻力、重力、前進方向和風力箭頭。風場採固定種子，因此相同設定可重複比較。柔軟度會讓兩側紙翼產生視覺彎曲，目前不會改變氣動力計算。

開啟作品或按重設後，預設使用「環視」。在環視模式下，任何時候都要按住滑鼠右鍵並移動才能旋轉視角。觸控螢幕可用手指滑動旋轉，滑鼠滾輪或雙指捏合可縮放。點一下 3D 畫面後，可用 WASD 平移鏡頭；飛行期間鏡頭不會自動跟隨，因此能直接觀察飛機移動軌跡。視角旋轉速度已調低。按「側視」、「跟隨」或「全景」即可切換預設鏡頭。

設定面板依序提供實驗目標、紙飛機、投擲和風場卡片；與目前目標較相關的卡片會以綠色標記。配重位置可直接拖曳紙飛機示意圖上的標記，進階氣流參數預設收合。風場卡片提供平穩基準、左右側風、強陣風、颱風和配重情境。底部固定「開始試飛」按鈕，試飛結果保留與上一次的比較。

本功能使用即時簡化氣動力學，不是逐點求解空氣流場的 CFD 或風洞模擬。氣動係數、姿態恢復、失速條件和場景尺度是教學近似，適合觀察參數間的相對影響，不應用來精準預測真實紙飛機的飛行距離。

## 技術

- React 19
- Vite 7
- Three.js
- Lucide React

## 本機執行

需要 Node.js 20 或更新版本。

```bash
npm install
npm run dev
```

開啟終端機顯示的本機網址即可使用。

## 正式建置

```bash
npm run build
```

輸出檔案位於 `dist/`。專案使用相對資源路徑，因此可將 `dist` 內容部署到 XAMPP 的子資料夾，例如：

```text
C:\xampp\htdocs\paperplane\
```

## 課堂用途

建議讓學生先建立基準試飛，每次只調整一個變因，先預測結果再重新試飛，比較配重、風向與環境對飛行的影響。
